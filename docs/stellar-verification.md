## 浏览器行为覆盖

1. 首页实际主入口走主题已有跃迁，受控正文内摘要/图谱各挂载一份。
2. 返航释放、二次入舱、独立正文接线。
3. SVG 不请求旧宠物精灵图，不启用帧循环；纯宠物模式仍可显示且不打开问答。
4. 名称、欢迎语、默认头像与问答入口统一为星枢领航员/星核徽记。
5. 系统浅色 + 站点深夜，以及系统深色 + 站点白昼，三个组件按站点口径显示。
6. 桌面/手机昼夜下小窗、全屏、关闭按钮可见，页面不横向溢出；宿主层级 280 让位装载/跃迁遮罩。
7. 摘要 UI 缺席时图谱独立挂载。
8. 配置请求在途换舱：旧占位不挂，新占位补扫不遗漏。
9. 摘要迟到响应不覆盖新文章；空态、业务失败与 HTTP 失败分别给出真实状态。
10. 图谱文章名变空时清理旧图与轮询；轮询预算耗尽后明确提示刷新，不假报仍会自动刷新。
11. 减弱动态效果时摘要直接显示，SVG 静态。
12. Clipboard API 缺席时真实复制按钮走降级并清理临时节点。
13. SVG 真拖动，靠近顶部/中部时小窗仍保持视口内。
14. 自定义头像失效回退 SVG 徽记。
15. 停止后立即再问，旧请求结算不得清掉新请求的停止句柄；新请求仍能停止。

测试中发现并修复：全屏网格的隐式列被快捷问题最小内容宽度撑开、移动小窗锚定方向在视口变化后未更新、全屏浮宠覆盖输入框、初次加载重复请求、配置在途换舱漏挂、无摘要业务响应被当正文、图谱轮询耗尽状态残留、停止/再问时旧请求清掉新句柄。

浏览器受控正文最初误复用了首页专用 data/app 脚本，其缺少首页 DOM 的异常已通过按真实文章模板范围筛选脚本消除；截图首帧透明度误差由等待入场动画结束消除。这些修正只作用于测试夹具，不修改主题。

## 警告与边界

- Impeccable 机械扫描报告摘要旧经典分支的弹性缓动两处，以及图谱既有引用 3px 左描边一处；都不属于新增星港样式，保留原风格兼容，不顺带重设计。
- 开发测试环境有 Lit 开发模式和 AI Foundation SDK 缺失源映射提示；发行产物为 Vite 生产构建。
- Gradle 在当前 JDK 上提示 native-access 与未来 Gradle 9 弃用兼容；本次未升级 Gradle/JDK/依赖。
- 控制台 UI 当前没有单元测试文件，现有任务使用 `--passWithNoTests`；不能计为管理界面功能测试通过。
- 主题音频在首次手势前会出现浏览器自动播放限制提示，非插件异常。
- 浏览器主动模拟 503 与失效头像时可能产生预期网络错误日志；验收要求没有未捕获页面异常。
- 本轮不覆盖真实模型质量、真实知识库权限/计费、插件安装升级全过程或既有摘要写入接口的安全问题。
